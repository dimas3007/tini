04 · Everything else

Small things, one glance away.

Now playing

Spotify, YouTube or any player. An equalizer while music plays; prev, play and next on hover.

Your own Stream Deck

Drag any app onto the notch and it's a button. Ctrl+Alt+1…0 runs them. Press one.

Smart chips

Copy a link or a screenshot, or finish a download, and the pill offers the next step: open, copy, save, show in folder.

Widgets

Prayer times calculated offline with the Kemenag method, and your last copied texts. Each one can be switched off.

Questions

Ask Nochi.

Is it free?
Yes. Free and open source, forever. A Pro version might come later, but it would only add new features.
Which agents work with it?
Claude Code gets the full live view, permission cards and quota. Codex, Gemini CLI, Cursor and any MCP agent can notify you and ask you questions.
Will it slow my PC down?
Under 15 MB of RAM in daily use and 0% CPU when idle. The animations run in Windows' own compositor.
When can I get it?
October 30 at 19:00 WIB. Watch the repo on GitHub and you'll know the moment it's out.
